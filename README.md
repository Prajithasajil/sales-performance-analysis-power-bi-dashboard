# Sales Performance Analysis Dashboard

## Project Overview

This project analyzes sales data using Microsoft Excel and Power BI to understand revenue trends, profitability, sales channel performance, and top-performing products.

## Tools Used

* Microsoft Excel
* Power BI
* DAX (Data Analysis Expressions)

## Key Performance Indicators

* Total Revenue
* Total Profit
* Total Orders
* Total Quantity Sold
* Profit Margin

## Analysis Performed

* Sales and profit by channel
* Monthly revenue and profit trends
* Top 10 products by revenue
* Revenue by city
* Interactive dashboard with channel and date filters

## Data Preparation

* Reviewed and prepared the sales dataset
* Calculated revenue, cost, and profit
* Created relationships between sales, customer, product, and regional tables
* Developed Power BI measures and visualizations

## Project Files

* **Sales Order Cleaned Dataset.xlsx** — Cleaned sales dataset
* **Sales Performance Analysis Dashboard.pbix** — Power BI dashboard

## Project Objective

To demonstrate practical beginner-level skills in data preparation, data analysis, KPI reporting, data modeling, and dashboard development using Excel and Power BI.
